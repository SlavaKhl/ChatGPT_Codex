# Ошибки

- 2026-08-29: Известных ошибок пока нет.
- 2026-08-30: Команда проверки `codex mcp list` в служебной оболочке не смогла определить `CODEX_HOME`; конфигурация записана корректно, но для появления MCP-инструментов в текущем клиенте требуется перезапуск Codex.
- 2026-08-30: Повторная проверка после продолжения сессии дала тот же результат: `codex mcp list` завершается ошибкой `failed to resolve CODEX_HOME`, а сервер `filesystem` отсутствует в доступном наборе MCP.
- 2026-08-30: Диагностика MCP выявила основную причину: на Windows дочерний процесс не может запустить `command = "npx"` (`ENOENT`), но `cmd.exe /c npx --version` успешно выполняется. Конфигурации `filesystem` требуется Windows-совместимая команда запуска через `cmd.exe`.
- 2026-08-30: Уточнение прежнего диагноза: пустой `resources: []` ошибочно трактовался как отсутствие подключения. `server-filesystem` предоставляет MCP-инструменты, а не статические ресурсы; прямые вызовы `list_allowed_directories` и `list_directory_with_sizes` успешны. Подключение фактически работает.
